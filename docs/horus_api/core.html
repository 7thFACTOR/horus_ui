Core

Contexts, the per-frame update/draw loop, input event handling, mouse cursors, clipboard and global settings.

Contexts

A context owns all the state of the UI. You usually create one per application (or per thread) with contextCreate, pass it user settings (including the Services callbacks) and make it current with contextSet.

HContext contextCreate(const Settings& settings)

Create a new context.

  • settings the startup context user defined settings (including services)

Returns the created context handle.

void contextSet(HContext ctx)

Set the current context.

  • ctx the context to make current
HContext contextGet()

Return the current context.

Returns the current context handle.

void contextDestroy(HContext ctx)

Delete a context and all its resources.

  • ctx the context to be deleted
Settings& contextGetSettings()

Return the context settings reference so you can read/modify them in real-time.

Frame and render cycle

The typical per-frame flow is contextUpdate → frameBegin → renderBegin → widget calls → renderEnd → frameEnd → present.

void contextUpdate()

Update the UI context: process input events, update animations, etc. Must be called once per frame, before frameBegin.

void frameBegin()

Begin a frame, i.e. the rendering of UI across one or many windows. Must be called first when rendering UI.

void frameEnd()

End a UI frame.

void renderBegin()

Begin the UI render command list. Called between frameBegin/frameEnd.

void renderEnd()

End and submit the UI render command list.

void renderCallbackAdd(RenderCallback callback)

Add a render callback at the current UI command list position. The callback is invoked when the UI is rendered and lets you issue custom rendering commands.

  • callback the callback, called with the native window being rendered
bool hasNothingToDo()

Return true when there is nothing to do in the UI (no redraw or layout work). Useful to stop rendering continuously in apps that don't need real-time redraw.

void skipRenderingThisFrame(bool disable)

Disable the rendering functions for this frame; used when only widget logic needs to run (mostly internal layout computation).

  • disable true to disable rendering
void forceRepaint()

Request the UI to be repainted due to data/layout changes.

void skipFrame()

If called, rendering and input are ignored until frameEnd and the loop will redraw again (mostly internal when layout is computed).

Frame time

f32 frameTimeGetLastMs()

Get the duration of the last UI frame in milliseconds.

f32 frameTimeGetPeakMs()

Get the peak (maximum) UI frame time in milliseconds since app start.

f32 frameTimeGetAvgMs()

Get the average UI frame time in milliseconds (rolling 60 frame window).

Clipboard

bool clipboardSetText(const char* text)

Copy UTF8 text to the clipboard.

  • text the null-terminated UTF8 text

Returns true if the text was copied.

bool clipboardGetText(char* outText, u32 maxTextSize)

Read UTF8 text from the clipboard.

  • outText caller-provided buffer for the text
  • maxTextSize the size of the buffer

Returns true if text was read.

Input events

Input providers push InputEvents into the queue and set the current one. The UI consumes the current event so every widget/window can react to it.

const InputEvent& inputEventGet()

Return the current input event popped from the event queue.

void inputEventCancel()

Cancel the current event; afterwards the event is null so no widget/window reacts to it.

void inputEventAdd(const InputEvent& event)

Add an input event to the queue. Used by input providers.

  • event the event to add
void inputSetMouseMoved(bool moved)

Signal that the mouse was moved. Used by input providers.

  • moved true if the mouse moved
size_t inputEventGetCount()

Return the number of events in the queue.

InputEvent inputEventGetAtIndex(size_t index)

Return a copy of the event at the given queue index.

  • index the event index
void inputEventSet(const InputEvent& event)

Set the current input event. Usually called by input providers.

  • event the event to set as current
void inputEventClearQueue()

Clear the input event queue. Usually called by input providers.

Mouse cursors

void mouseCursorSetType(MouseCursorType type)

Set the current mouse cursor type (a named OS cursor).

  • type the cursor type
HMouseCursor mouseCursorCreate(Rgba32* pixels, u32 width, u32 height, u32 hotSpotX = 0, u32 hotSpotY = 0)

Create a custom mouse cursor from a bitmap.

  • pixels 32-bit RGBA bitmap
  • width cursor width
  • height cursor height
  • hotSpotX hot spot X from the top-left
  • hotSpotY hot spot Y from the top-left

Returns the created cursor handle.

void mouseCursorDestroy(HMouseCursor cursor)

Delete a custom mouse cursor.

  • cursor the cursor to delete
void mouseCursorSet(HMouseCursor cursor)

Set a custom mouse cursor as current.

  • cursor the cursor to set
