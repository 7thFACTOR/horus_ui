Windowing & toolbars

Native windows, the dock node layout, dockable windows, docking layout persistence and overlay toolbars.

How windows and docking work

Horus windows live inside a dock tree. Each native window gets a root dock node ( dockNodeCreateRoot); dock nodes split into child nodes (dockNodeSplit) and windows are assigned to nodes (dockNodeSetWindow). A window is drawn between windowBegin/windowEnd from inside any layout, and the user can drag/drop tabs to re-dock them at runtime.

Native windows & the dock tree

void nativeWindowSetCurrent(HNativeWindow nativeWnd)

Set the current native OS window; subsequent window drawing happens inside it.

  • nativeWnd the native window handle
DockNodeId dockNodeCreateRoot(HNativeWindow nativeWnd)

Create the root dock node of a native window. All of that window's docked content lives under this root.

  • nativeWnd the native window handle

Returns the new root dock node id.

void dockNodeDeleteChildren(DockNodeId rootNodeId)

Delete the children of a dock node, removing the windows docked in them.

  • rootNodeId the dock node whose children are deleted
void dockNodeSplit(DockNodeId nodeId, DockNodeSplitType splitType, f32 firstNodeSizeUnitPercent, DockNodeId* outNodeId1, DockNodeId* outNodeId2)

Split a dock node into two sibling nodes, replacing it in the tree.

  • nodeId the node to split
  • splitType the split direction
  • firstNodeSizeUnitPercent size of the first child as unit percent (0..1)
  • outNodeId1 receives the first child node id
  • outNodeId2 receives the second child node id
void dockNodeSetWindow(DockNodeId parentNode, const char* windowId)

Assign a window to a dock node. Call before the window is first drawn so it knows where to dock.

  • parentNode the dock node to host the window
  • windowId the window id
void dockNodeLayoutRecalculate()

Recalculate the dock node layout sizes from the native window sizes.

Dockable windows

bool windowBegin(const char* windowId, const char* title, Rect* initialRect = nullptr, HImage img = 0)

Begin a dockable window. The window is created on first call and remembers its dock position across frames.

  • windowId the unique window id
  • title the window title
  • initialRect optional initial window rect in window coordinates
  • img optional window image (icon) in the tab/title

Returns true if the window is open/visible and its layout was started; draw its contents inside if (windowBegin(...)).

void windowEnd()

End the current dockable window.

void windowSetVisible(const char* windowId, bool visible)

Show or hide a window.

  • windowId the window id
  • visible true to show, false to hide
void windowSetNextFlags(WindowFlags flags)

Set the flags applied to the next window created.

  • flags the window flags
void windowSetNextSize(f32 width, f32 height)

Set a fixed size for the next window drawn, the dock node keeps this size instead of scaling with the native window.

Call this every frame only for windows that must stay fixed, such as menu/toolbar chrome. Setting it every frame for a resizable panel forces it back to this size on each dock layout recalculation, overriding the user's splitter position.

  • width the fixed width, 0 for auto
  • height the fixed height, 0 for auto
void windowSetFocus(const char* windowId)

Give keyboard focus to a window.

  • windowId the window id
void windowDock(const char* windowId, const char* targetWindowId, DockType dockType)

Programmatically dock a window into another window.

  • windowId the window to dock
  • targetWindowId the target window to dock into
  • dockType the docking mode (Left/Right/Top/Bottom/AsTab/Floating)
void windowUndock(const char* windowId, const Point& windowPos = Point())

Undock a window, making it a floating window.

  • windowId the window to undock
  • windowPos the window position in screen coordinates
void windowDebugPrint()

Debug-print the docking layout tree to stdout.

bool windowIsMouseOver()

Return true if the mouse is over the current window.

void windowSetCapture()

Capture mouse input to the current window.

void windowReleaseCapture()

Release the mouse capture from the current window.

Rect windowGetClientRect()

Return the current window's client rect (in window coordinates).

Rect windowGetClientRectByWindowId(const char* windowId)

Return the client rect of the given window, usually used to render custom scenes.

  • windowId the window id

Docking layout persistence

void dockingStateSave(WindowsDockingState& dockingState)

Save the current docking layout into a state object (to store on disk or in a project file).

  • dockingState the state to fill
void dockingStateLoad(const WindowsDockingState& dockingState)

Restore a previously saved docking layout.

  • dockingState the state to load

Overlay toolbars

Overlay toolbars are dockable strips that float over a viewport. Wrap the whole toolbar pass in overlayToolbarsBegin/overlayToolbarsEnd, then call overlayToolbarBegin/overlayToolbarEnd for each toolbar and add its widgets in between. Toolbars can be docked to an edge of the viewport or left floating, and are identified by a string id.

void overlayToolbarsBegin(const Rect& viewportRect)

Begin the overlay toolbar system for a viewport rect.

  • viewportRect the viewport rect in window coordinates
void overlayToolbarsEnd()

End the overlay toolbar system.

bool overlayToolbarBegin(const char* id, const char* title, OverlayDockZone dockZone = OverlayDockZone::Floating, OverlayToolbarLayout layout = OverlayToolbarLayout::Horizontal)

Begin an overlay toolbar.

  • id the unique toolbar id
  • title the toolbar title (shown when collapsed)
  • dockZone the dock zone (Floating by default)
  • layout the toolbar layout (Horizontal by default)

Returns true if the toolbar is open, false if collapsed/hidden.

void overlayToolbarEnd()

End the current overlay toolbar.

bool overlayToolbarButton(const char* elementId, const char* label, HImage icon = 0, void (*onClick)() = nullptr, const char* tooltip = nullptr)

Add a button to the current toolbar.

  • elementId the unique element id inside the toolbar
  • label the button label
  • icon the button icon image
  • onClick function called when clicked
  • tooltip the button tooltip text

Returns true if clicked.

bool overlayToolbarToggle(const char* elementId, const char* label, HImage iconOff, HImage iconOn, bool* toggleValue, void (*onToggle)(bool) = nullptr, const char* tooltip = nullptr)

Add a toggle button to the current toolbar.

  • elementId the unique element id inside the toolbar
  • label the toggle label
  • iconOff the image shown when the toggle is off
  • iconOn the image shown when the toggle is on
  • toggleValue points to the bool value of the toggle
  • onToggle callback when the toggle value changes (receives the new value)
  • tooltip the toggle tooltip text

Returns true if toggled.

void overlayToolbarDropdown(const char* elementId, const char** items, u32 itemCount, i32* selectedIndex, void (*onSelect)(i32) = nullptr, HImage icon = 0, const char* tooltip = nullptr)

Add a dropdown list button to the current toolbar, showing the selected item. The chosen item is reported through the onSelect callback.

  • elementId the unique element id inside the toolbar
  • items the array of item labels
  • itemCount the number of items
  • selectedIndex the currently selected item index (in/out)
  • onSelect callback when an item is selected (receives the new index)
  • icon optional icon shown before the text
  • tooltip the dropdown tooltip text
void overlayToolbarSeparator()

Add a separator to the current toolbar.

void overlayToolbarSpace()

Add a space to the current toolbar.

void overlayToolbarGrip()

Add a grip to the current toolbar, used for dragging.

void overlayToolbarSetGridAlignment(bool enable, f32 gridSize = 0)

Set grid snapping for floating toolbars.

  • enable true to enable grid snapping
  • gridSize the grid size in pixels (0 to use the global setting)
void overlayToolbarSetCustomSize(const Point& size, bool useCustomSize = true)

Set a custom size for the current floating toolbar.

  • size the custom size (width, height)
  • useCustomSize true to use the custom size, false to size from content
void overlayToolbarSetFloatingPosition(const Point& pos)

Set the floating position for the current floating toolbar, relative to the viewport.

  • pos the position relative to the viewport
Point overlayToolbarGetFloatingPosition()

Return the floating position of the current floating toolbar relative to the viewport (updated after a drag).

void overlayToolbarSetCollapsed(bool collapsed)

Set the collapsed state for the current toolbar.

  • collapsed true to collapse the toolbar
bool overlayToolbarIsCollapsed()

Return true if the current toolbar is collapsed.

Rect overlayToolbarGetDockZoneRect(const Rect& viewportRect, OverlayDockZone zone, f32 toolbarThickness = 32.0f)

Return the rect of a dock zone inside a viewport rect.

  • viewportRect the viewport rect
  • zone the dock zone
  • toolbarThickness the thickness of the toolbar in the dock zone
bool overlayToolbarPointInDockZone(const Rect& viewportRect, const Point& pt, OverlayDockZone zone, f32 toolbarThickness = 32.0f)

Return true if a point is inside a dock zone rect.

  • viewportRect the viewport rect
  • pt the point to test
  • zone the dock zone
  • toolbarThickness the thickness of the toolbar in the dock zone
bool overlayToolbarContainsPoint(const Point& viewportPoint)

Return true if a point relative to the overlayToolbarsBegin viewport rect is inside any visible toolbar or an open dropdown popup of a toolbar.

  • viewportPoint the point relative to the overlayToolbarsBegin viewport rect
