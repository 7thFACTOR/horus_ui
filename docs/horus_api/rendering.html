Rendering & Utility

Custom widgets, layer indices, immediate-mode drawing primitives, drag & drop, complex combined widgets (color picker, file dialog, vector editors, object ref editor), color/string utilities, and demo window.

Custom widgets & layers

Rect customWidgetBegin(const char* id, f32 height = 0.0f)

Begin drawing a custom widget.

  • id the widget id
  • height the widget height

Returns the widget rectangle in window coordinates.

void customWidgetEnd()

End custom widget drawing.

void layerIndexIncrement()

Increment the current UI layer index, used to draw widgets in higher layers (drawn on top).

u32 layerIndexDecrement()

Decrement the current UI layer index.

Returns the layer index after decrementing.

void layerDecrementWindowMaxLayerIndex()

Decrement the maximum layer index of the current window, used internally when a window's layer stack ends.

Immediate-mode drawing primitives

These functions draw directly into the current render command list. They use the current line style, fill style and render color (set via renderSetLineStyle, renderSetFillStyle, renderSetColor).

void renderSetLineStyle(const LineStyle& style)

Set the current line drawing style.

void renderSetFillStyle(const FillStyle& style)

Set the current fill drawing style.

void renderSetColor(const Color& color)

Set the current render color.

void renderDrawTextInBox(const char* text, const Rect& rect, HAlignType horizontalAlign, VAlignType verticalAlign)

Draw text inside a rectangle, aligned within it.

Point renderGetTextSize(const char* text)

Return the pixel size (width, height) of the given text with the current font.

void renderDrawImage(HImage image, const Point& position, f32 scale)

Draw an image at a position with a given scale.

void renderDrawStretchedImage(HImage image, const Rect& rect)

Draw an image stretched to fill a rectangle.

void renderDrawBorderedImage(HImage image, u32 border, const Rect& rect)

Draw a 9-cell border image to fill a rectangle.

void renderDrawLine(const Point& a, const Point& b)

Draw a line between two points.

void renderDrawPolyLine(const Point* points, u32 pointCount, bool closed = false)

Draw a connected line through the given points.

void renderDrawCircle(const Point& center, f32 radius, u32 segments = 32)

Draw a circle outline.

void renderDrawEllipse(const Point& center, f32 radiusX, f32 radiusY, u32 segments = 32)

Draw an ellipse outline.

void renderDrawRectangle(const Rect& rc)

Draw a rectangle outline.

void renderDrawSolidRectangle(const Rect& rc)

Draw a solid (filled) rectangle.

void renderDrawSpline(SplineControlPoint* points, u32 count, f32 segmentSize = 15)

Draw a spline through the given control points.

void renderDrawArrow(const Point& startPoint, const Point& endPoint, f32 tipLength, f32 tipWidth, bool drawBodyLine = true)

Draw an arrow from a start point to an end point.

void renderDrawSolidTriangle(const Point& p1, const Point& p2, const Point& p3)

Draw a solid (filled) triangle.

Complex / combined widgets

bool colorPicker(const char* id, Color* inOutColor, ColorPickerFlags flags = 0, const Color* oldColor = nullptr, Color* customColors = nullptr, u32* customColorCount = nullptr, u32 maxCustomColors = 0)

Draw a color picker popup widget.

  • id unique widget id
  • inOutColor the color to edit (in/out)
  • flags the color picker flags (ColorPickerFlags)
  • oldColor optional previous color for comparison
  • customColors optional array of custom swatch colors (requires ShowPalette flag)
  • customColorCount pointer to number of custom colors (in/out)
  • maxCustomColors max capacity of the customColors array

Returns true if the color was changed.

bool colorPickerPopup(const char* id, Color* inOutColor, ColorPickerFlags flags = 0, const Color* oldColor = nullptr, Color* customColors = nullptr, u32* customColorCount = nullptr, u32 maxCustomColors = 0)

Draw a color picker popup (a color swatch that opens a full color picker in a popup on click).

bool customFileDialog(const char* id, CustomFileDialogListCallback listCallback, void* userData, char* outResult, u32 resultBufferSize, CustomFileDialogFlags flags = CustomFileDialogFlags::None, CustomFileDialogPreviewCallback previewCallback = nullptr, void* previewUserData = nullptr, CustomFileDialogCreateFolderCallback createFolderCallback = nullptr, void* createFolderUserData = nullptr)

Draw a custom file dialog widget, a popup like the OS file dialogs, that navigates a virtual file system provided by the listCallback.

  • id unique widget id
  • listCallback the callback that lists the contents of a path
  • userData user data passed to the listCallback
  • outResult buffer where the chosen path is written when the dialog is confirmed
  • resultBufferSize the size of the outResult buffer in bytes
  • flags the dialog flags (CustomFileDialogFlags)
  • previewCallback optional callback to draw a preview of the selected entry
  • previewUserData user data passed to previewCallback
  • createFolderCallback optional callback that creates a folder in the current path
  • createFolderUserData user data passed to createFolderCallback

Returns true when a path was chosen, in this case outResult is filled with the chosen path.

Color utilities

Color colorFromText(const char* colorText)

Create a color from a text string, supports named colors (like "red", "darkBlue") and "r g b a" components (0-255).

Returns the parsed color, white if the text can't be parsed.

Color colorFromHex(const char* hexText)

Create a color from a hex string like "#RRGGBB" or "RRGGBBAA".

Returns the parsed color, white if the text can't be parsed.

u32 colorIntFromHex(const char* hexText)

Create an RGBA color value from a hex string like "#RRGGBB" or "RRGGBBAA".

Returns the RGBA color value.

std::string colorToHex(const Color& color)

Convert a color to a hex string like "#RRGGBB" (or with alpha "#RRGGBBAA" when not fully opaque).

std::string colorIntToHex(u32 color)

Convert an RGBA color value to a hex string like "#RRGGBB" (or with alpha "#RRGGBBAA" when not fully opaque).

Color colorHsvToRgb(const Color& hsv)

Convert a color from HSV to RGB.

  • hsv the HSV color with channels in the 0..1 range
Color colorRgbToHsv(const Color& rgb)

Convert a color from RGB to HSV.

  • rgb the RGB color with channels in the 0..1 range
Color colorHueToRgb(f32 h, f32 alpha)

Create a color from a hue.

  • h the hue value in the 0..1 range
  • alpha the alpha channel value
