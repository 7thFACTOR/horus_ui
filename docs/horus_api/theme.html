Themes & fonts

Creating and managing themes, widget element styles and parameters, plus fonts and image queries. The full theme json format is documented in Theme JSON Format.

Themes

A theme owns an image atlas, widget element styles and fonts. Create one, register its images with themeAddImage, then build its atlas with themeBuild before making it current with themeSet.

void themeSet(HTheme theme)

Set the current theme.

  • theme the theme to be set as current
HTheme themeGet()

Return the current theme.

HTheme themeCreate(u32 atlasTextureSize)

Create a new theme.

  • atlasTextureSize the width and height of the atlas texture where theme images are kept

Returns the newly created theme.

HTheme createBuiltinTheme(u32 atlasTextureSize)

Create a new theme filled with the built-in element styles and images.

  • atlasTextureSize the width and height of the atlas texture where theme images are kept

Returns the newly created theme.

void themeDestroy(HTheme theme)

Delete a theme. If it is the current theme, the current theme is reset to null.

  • theme the theme to be deleted
ImageData themeGetAtlasImageData()

Return the pixel data (pixels, width, height) of the current theme's atlas texture.

void themeSetAtlasTexture(HTexture texture)

Set the current theme's atlas texture to a custom texture, usually after the theme was built once and its atlas was moved to video memory.

  • texture the texture handle
HTexture themeGetAtlasTexture()

Return the atlas texture of the current theme.

void themeSetUserSetting(HTheme theme, const char* name, const char* value)

Set a user setting on a theme.

  • theme the theme handle
  • name the setting name
  • value the setting value
const char* themeGetUserSetting(HTheme theme, const char* name)

Get a user setting from a theme.

  • theme the theme handle
  • name the setting name

Returns the setting value, or null if it doesn't exist.

HImage themeAddImage(HTheme theme, const char* id, const ImageData& imgData)

Add an image to a theme. Must be called before the theme is built.

  • theme the theme handle
  • id the unique image id
  • imgData the image data to add

Returns the added image handle.

HImage themeGetImage(HTheme theme, const char* id)

Get an image from a theme by id.

  • theme the theme handle
  • id the image id

Returns the image handle, or null.

void themeBuild(HTheme theme)

Build a theme after its images were added, packing the theme's image atlas.

  • theme the theme to be built
bool themeRebuildAtlas(HTheme theme)

Rebuild the theme's image atlas if it was marked dirty (e.g. after adding images dynamically).

  • theme the theme to be rebuilt

Returns true if the atlas was rebuilt, false if it was already up to date.

Widget element styles

Widgets look up their theme style by widget type and element id. These functions select which style is used.

void widgetSetStyle(WidgetType widgetType, const char* styleName)

Set the current style of a widget type, used by subsequent widgets.

  • widgetType the widget type
  • styleName the style name
void widgetPushStyle(WidgetType widgetType, const char* styleName)

Push the current style of a widget type and set a new one.

  • widgetType the widget type
  • styleName the style name
void widgetPopStyle()

Pop the previously pushed style of a widget type.

void widgetSetElementStyle(WidgetElementId widgetElementId, const char* styleName)

Set the current style of a widget element.

  • widgetElementId the widget element
  • styleName the style name
void widgetSetDefaultStyle(WidgetType widgetType)

Set a widget type to its default style.

  • widgetType the widget type
void widgetSetDefaultElementStyle(WidgetElementId widgetElementId)

Set a widget element to its default style.

  • widgetElementId the widget element
void widgetSetUserElementStyle(const char* elementName, const char* styleName)

Set the style of a user (custom) widget element.

  • elementName the user element name
  • styleName the style name

Element infos & parameters

Element infos describe the image, border and per-state data used to draw a widget element. User elements are defined in a theme under names like user.customName and drawn with customWidget (see Rendering).

void themeSetWidgetElement(HTheme theme, WidgetElementId elementId, WidgetStateType widgetStateType, const WidgetElementInfo& elementInfo, const char* styleName = "default")

Set a theme's widget element info for a given state and style.

  • theme the theme of the widget element
  • elementId the element to be set
  • widgetStateType which state to be set
  • elementInfo the element info to be set
  • styleName the style name
void themeSetUserWidgetElement(HTheme theme, const char* userElementName, WidgetStateType widgetStateType, const WidgetElementInfo& elementInfo, const char* styleName = "default")

Set a theme's user widget element info for a given state and style.

  • theme the theme of the widget element
  • userElementName the element name
  • widgetStateType which state to be set
  • elementInfo the element info to be set
  • styleName the style name
void themeGetWidgetElementInfo(WidgetElementId elementId, WidgetStateType state, WidgetElementInfo& outInfo, const char* styleName = "default")

Return the current theme's widget element info.

  • elementId the widget element id
  • state the element state
  • outInfo receives the element info
  • styleName the style name
void themeGetUserWidgetElementInfo(const char* userElementName, WidgetStateType state, WidgetElementInfo& outInfo, const char* styleName = "default")

Return the current theme's user widget element info.

  • userElementName the user element name
  • state the element state
  • outInfo receives the element info
  • styleName the style name
void themeSetWidgetElementParameter(HTheme theme, WidgetElementId elementId, const char* styleName, const char* paramName, const char* paramValue)

Set a parameter of a theme widget element style.

  • theme the theme handle
  • elementId the widget element
  • styleName the style name
  • paramName the parameter name
  • paramValue the parameter value
const char* themeGetWidgetElementParameterString(HTheme theme, WidgetElementId elementId, const char* styleName, const char* paramName, const char* defaultValue = "")

Get a string parameter of a theme widget element style.

  • theme the theme handle
  • elementId the widget element
  • styleName the style name
  • paramName the parameter name
  • defaultValue the value returned if the parameter doesn't exist

Returns the parameter value.

f32 themeGetWidgetElementParameterFloat(HTheme theme, WidgetElementId elementId, const char* styleName, const char* paramName, f32 defaultValue = 0.0f)

Get a float parameter of a theme widget element style.

  • theme the theme handle
  • elementId the widget element
  • styleName the style name
  • paramName the parameter name
  • defaultValue the value returned if the parameter doesn't exist

Returns the parameter value.

const Color& themeGetWidgetElementParameterColor(HTheme theme, WidgetElementId elementId, const char* styleName, const char* paramName, const Color& defaultValue = Color())

Get a color parameter of a theme widget element style. The parameter value must be a color string.

  • theme the theme handle
  • elementId the widget element
  • styleName the style name
  • paramName the parameter name
  • defaultValue the value returned if the parameter doesn't exist

Returns the parameter value.

void themeSetUserWidgetElementParameter(HTheme theme, const char* userElementName, const char* styleName, const char* paramName, const char* paramValue)

Set a parameter of a user widget element style.

  • theme the theme handle
  • userElementName the user element name
  • styleName the style name
  • paramName the parameter name
  • paramValue the parameter value
const char* themeGetUserWidgetElementParameterString(HTheme theme, const char* userElementName, const char* styleName, const char* paramName, const char* defaultValue = "")

Get a string parameter of a user widget element style.

  • theme the theme handle
  • userElementName the user element name
  • styleName the style name
  • paramName the parameter name
  • defaultValue the value returned if the parameter doesn't exist

Returns the parameter value.

f32 themeGetUserWidgetElementParameterFloat(HTheme theme, const char* userElementName, const char* styleName, const char* paramName, f32 defaultValue = 0.0f)

Get a float parameter of a user widget element style.

  • theme the theme handle
  • userElementName the user element name
  • styleName the style name
  • paramName the parameter name
  • defaultValue the value returned if the parameter doesn't exist

Returns the parameter value.

const Color& themeGetUserWidgetElementParameterColor(HTheme theme, const char* userElementName, const char* styleName, const char* paramName, const Color& defaultValue = Color())

Get a color parameter of a user widget element style. The parameter value must be a color string.

  • theme the theme handle
  • userElementName the user element name
  • styleName the style name
  • paramName the parameter name
  • defaultValue the value returned if the parameter doesn't exist

Fonts

HFont themeFontCreate(HTheme theme, const char* name, const char* fontFilename, u32 faceSize)

Create a new font object in a theme.

  • theme the theme where to place the font
  • name the name of the font (e.g. smallItalic)
  • fontFilename the TTF/OTF filename, relative to the executable
  • faceSize the font face size in font units

Returns the newly created font handle.

void themeFontDestroy(HTheme theme, HFont font)

Release a font reference. If its usage count reaches zero the font is deleted.

  • theme the theme owning the font
  • font the font to release
HFont themeFontGet(const char* themeFontName)

Return a font by name from the current theme.

  • themeFontName the name of the font as it is in the theme
HFont themeFontGetFromTheme(HTheme theme, const char* themeFontName)

Return a font by name from the specified theme.

  • theme the theme to search
  • themeFontName the name of the font as it is in the theme
Point fontGetTextSize(HFont font, const char* text)

Return the pixel size of the given text when rendered with the given font.

FontMetrics fontGetMetrics(HFont font)

Return the line metrics (height, ascender, descender) of the given font.

Images

Point imageGetDimensions(HImage image)

Return the pixel width and height of the given image, {0, 0} if the image is null.

The theme json structure, element names and style params are covered in detail by Theme JSON Format.
