Themes & fonts

Themes, element styles (hiding, styling and info), user-defined element data, plus font and image loading. The full theme json format is documented in Theme JSON Format.

Themes

size_t themesGetCount()

Return the number of loaded themes.

ThemeHandle themeCreate(const u8* data, size_t dataSize)

Load a theme from raw bytes (the file content of a theme json).

  • data the theme file data
  • dataSize the size of the data

Returns the theme handle, or null if loading failed.

ThemeHandle themeCreateFromFile(const char* path)

Load a theme from a file.

  • path the theme file path

Returns the theme handle, or null if loading failed.

void themeSetFontFace(ThemeHandle theme, HFontFace fontFace)

Set the default font face of a theme, resolved from the theme json name or overridden at runtime.

void themeSet(const char* themeName)

Set the current theme by name (as a user element: name = theme@<name>).

void themeDelete(ThemeHandle theme)

Delete a theme and its font face.

HFontFace themeGetFontFace(ThemeHandle theme)

Return the font face of a theme, or null.

HFontFace themeGetFontFaceByName(const char* themeName)

Return the font face of a theme by name, or null.

bool uiThemeBegin(const char* themeName = nullptr)

Begin the theme set by themeSet, or the given theme name. Call once per frame before drawing the UI.

void uiThemeEnd()

End the UI theme pass.

HImage uiThemeGetImage(const char* name)

Return an image loaded by the current theme, or null.

bool uiThemeGetBoolParam(const char* name, bool* outParampParam)

Look up a boolean theme parameter (a Params entry of the current theme json).

Element styles

Elements (both user elements and prebuilt widget styles) can be hidden, styled and queried at runtime.

void elementSetEnabled(const char* elementName)

Enable all element styles matching the name (see Theme JSON).

void elementSetDisabled(const char* elementName)

Disable all element styles matching the name; their elements still exist but are not drawn.

void elementGetEnabledInfos(std::vector<ElementInfo>& outElementInfos, const char* elementName = nullptr)

Return the current enabled element styles, optionally filtered by name.

void elementSetStyleParam(const char* elementName, ElementStyleType paramType, f32 value)

Set a scalar style parameter on all matching star-style elements.

void elementSetStyleParamAp(const char* elementName, ElementStyleType paramType, Rgba32 value)

Set a color (RGBA) style parameter on all matching star-style elements.

u8 elementGetEnabledCount()

Return the number of enabled element styles.

const ElementInfo* elementGetEnabledAt(u16 index)

Return the enabled element style info at the given index, or null.

User elements & custom data

User elements are elements defined in a theme under names like user.customName. They are drawn by your code with customWidget (see Rendering).

void elementSetStateParams(ElementState state, const Scale9* scale9 = nullptr, const Rgba32* color = nullptr)

Set the current state parameters for the next element style built (used by the theme builder and tests).

void elementAddStateParams(ElementInfo* info, ElementState state)

Add a state and its parameters to an element info (theme builder + tests).

void elementSetBuilderUsed()

Mark that the user is using the element builder API, bypassing the json loader.

std::vector<std::string> elementBuilderGetElementNames()

Return the names of all elements set through the builder API.

void elementSequenceAppendFromJson(const char* name, const u8* data, size_t dataSize)

Append one element style to the current state of the async loading sequence.

bool elementGetStyleParams(const char* elementName, ElementState state, const Scale9** outScale9, const Rgba32** outColor)

Return the scale9 and color params of a named element style at a given state, if it exists.

bool elementGetStyleParamFloat(const char* elementName, ElementState state, ElementStyleParamsType styleType)

Return a float style param of a named element style at a given state.

bool elementHasStyleParamsOfType(const char* elementName, ElementState state, ElementStyleParamsType styleParamsType)

Return true if a named element style defines a specific param type at a given state.

Fonts & images

HFontFace fontFaceCreate(const char* path = nullptr)

Create a font face from a TTF file, or load the default embedded font if no path is given.

HFont fontGet(HFontFace fontFace, f32 pixHeight = 32.0f)

Get or create a font at the given pixel height.

FontInfo fontGetInfo(u32 fontIndex)

Return metrics about a font: ascent, descent, unitsPerEm, lineGap.

HImage imageCreateFromFile(const char* path)

Load an image from a file (PNG, JPG, BMP, QOI), PNG format is recommended.

void imageDelete(HImage img)

Delete an image and free its GPU resource.

u32 imageGetWidth(HImage img)

Return the width of an image in pixels.

u32 imageGetHeight(HImage img)

Return the height of an image in pixels.

Theme build & validation

bool themeBuildElements(const u8* data, size_t dataSize)

Build all element styles from theme data into the global context style array. Used by the theme build/load pipeline; typically not called from user code.

bool validateJsTheme(const u8* data, size_t dataSize, char* outErrors)

Validate theme json data; report errors in the caller-provided buffer.

The theme json structure, element names and style params are covered in detail by Theme JSON Format.
