Layout & Tables

Layout areas, the id stack, tables, scroll views, virtual lists, padding, spacing, scale, tint, same-line groups and delayed tooltips.

Layout areas

void layoutBegin(const Rect& rect)

Begin a layout area, an invisible rectangle on the current window area where widgets will be laid out.

  • rect the layout rectangle
void layoutEnd()

End the current layout area.

void layoutPush()

Push the current layout state (position, size, spacing and same-line state) and start a new one, helper for nested layouts.

void layoutPop()

Pop the previously pushed layout state, restoring the outer layout.

f32 layoutGetRemainingHeight()

Get the remaining height in the current layout from current position to bottom.

f32 layoutGetRemainingWidth()

Get the remaining width in the current layout from current position to right edge.

Point layoutGetSize()

Return the size of the current layout in unscaled pixels.

ID stack

The id stack scopes widget ids. Push before a group of widgets, pop after.

void idPush(const char* id)

Push a string id on the id stack.

  • id the id to push
void idPush(u32 id)

Push a numeric id on the id stack.

  • id the id to push
void idPush(void* id)

Push a pointer id on the id stack.

  • id the pointer id to push
void idPop()

Pop the previously pushed id from the id stack.

Tables

bool tableBegin(const char* id, u32 columnCount, f32 height = -1, TableFlags flags = TableFlags::None)

Begin a table widget.

  • id the unique widget id
  • columnCount the number of columns
  • height the table height, if zero or negative it uses the remaining layout height
  • flags the table flags (TableFlags)

Returns true if there is space to draw the table and its layout was begun.

void tableEnd()

End the current table widget.

void tableStartHeader()

Start the table header row; all cells drawn after this until the first tableRowNext make the header row.

void tableColumnSetup(u32 columnIndex, f32 size, TableColumnFlags flags = TableColumnFlags::None)

Configure a table column.

  • columnIndex the column index to configure
  • size the column size in pixels
  • flags the column flags (TableColumnFlags)
void tableRowNext()

End the current table row and move to the next one.

void tableRowSetColor(const Color& color)

Set the background color of the current table row.

  • color the row color
void tableCellNext(u32 columnSpan = 1)

Move to the next cell in the current table row.

  • columnSpan the number of columns this cell spans
Rect tableCellGetRect()

Return the rect of the current table cell, in window coordinates.

void tableCellSetColor(const Color& color)

Set the background color of the current table cell.

  • color the cell color
void tableCellPaddingPush(f32 paddingX, f32 paddingY)

Push the current cell padding and set a new one.

  • paddingX the new horizontal cell padding
  • paddingY the new vertical cell padding
void tableCellPaddingPop()

Pop the previous cell padding.

Scroll views

void scrollViewBegin(const char* id, f32 height, f32 scrollPosition, f32 virtualHeight, ScrollViewFlags flags)

Begin a scroll view area widget.

  • id the unique widget id
  • height the height of the scroll area
  • scrollPosition the current scroll position (given by scrollViewEnd)
  • virtualHeight the virtual inside scroll height; if zero, automatically calculated from child widgets
  • flags the scroll view flags (ScrollViewFlags)
void scrollViewBegin(const char* id, f32 size, f32 scrollPos)

Convenience overload with a single f32 scroll position and no flags.

void scrollViewBegin(const char* id, f32 size, f32 scrollPos, f32 virtualHeight)

Convenience overload with a virtual height and no flags.

void scrollViewBegin(const char* id, f32 height, Point scrollOffset, Point virtualSize, ScrollViewFlags flags)

Convenience overload with flags and a virtual size (both horizontal and vertical).

Point scrollViewEnd()

End a scroll view area widget.

Returns the current scroll position (offset).

void scrollViewScrollToWidget(WidgetId id = 0, ScrollToItemSnapMode mode = ScrollToItemSnapMode::Minimal)

Scroll the view to the bounds of the last submitted widget (or a specific widget if id is provided). When called inside a virtual list, id is interpreted as the virtualItemIndex.

Virtual lists

For lists with many items. Use inside scrollViewBegin/End.

void virtualListContentBegin(u32 totalRowCount, f32 itemHeight, f32 scrollPosition)

Begin a virtual list content area.

  • totalRowCount the number of rows
  • itemHeight the height of one item
  • scrollPosition the current scroll offset of the scroll view widget
void virtualListContentBegin(VirtualScrollInfo& info)

Begin a virtual list content area using a VirtualScrollInfo struct.

void virtualListContentEnd()

End a virtual list content area.

Padding, spacing, scale & tint

void paddingPush(PaddingType type, const Point& newPadding)

Push the old padding and set a new one; padding is the left/right horizontal spacing for widgets.

void widgetPaddingPush(const Point& newPadding)

Push the old widget padding and set a new one, only affects subsequent widgets.

void paddingPop(PaddingType type)

Pop the previous padding value from stack and set it as current.

void widgetPaddingPop()

Pop the previous widget padding.

f32 spacingGet()

Return the current vertical spacing value.

const Point& paddingGet(PaddingType type)

Return the current horizontal left and right side padding value.

const Point& widgetGetPadding()

Return the current widget padding, shorthand for paddingGet(PaddingType::Widget).

void spacingPush(f32 newSpacing)

Push and set a new spacing value; spacing is the vertical space between widgets.

void spacingPop()

Pop old spacing value from stack and set it as current.

void scaleSet(f32 scale)

Set the global UI scale; this will scale all elements from widgets to text. Use with consideration, regenerates font atlas, slow.

f32 scaleGet()

Return the current global UI scale.

void tintPush(const Color& color, TintColorType type = TintColorType::All, TintColorOpType opType = TintColorOpType::Multiply)

Push and set a new tinting color on stack, to colorize the next widget on specific parts.

void tintPop()

Pop the old tint color from stack.

Color tintApply(const Color& originalColor, TintColorType type)

Apply the current tint color to a color.

Same-line groups

void sameLineGroupBegin(u32 widgetCount)

Begin a same-line group where all widgets get equal width from available layout width.

void sameLineGroupNext()

Move to the next widget position in the same-line group.

void sameLineGroupEnd()

End the same-line group.

Delayed tooltips

bool tooltip(const char* text)

Draw a delayed tooltip widget near the previous widget.

  • text the label of the tooltip

Returns true if the tooltip is visible now.

bool customTooltipBegin(f32 width)

Begin drawing a custom tooltip (delayed), which contains other widgets like image and labels etc.

void customTooltipEnd()

End drawing a custom tooltip.
