Callbacks

typedef void (*RenderCallback)(HNativeWindow wnd);

Renders custom content when the UI command list is submitted.

  • wnd the native window being rendered to
typedef void (*CustomFileDialogListCallback)(const char* path, std::vector<CustomFileDialogEntry>& outEntries, void* userData);

Lists the contents of a path for the custom file dialog.

  • path the absolute path to list
  • outEntries filled with the entries found in path
  • userData the user data passed to customFileDialog
typedef bool (*CustomFileDialogCreateFolderCallback)(const char* path, const char* folderName, void* userData);

Creates a folder in the current path for the custom file dialog. Return true when created; when nullptr the dialog hides the "New folder" button.

  • path the absolute current path of the dialog
  • folderName the name of the folder to create
  • userData the user data passed to customFileDialog
typedef void (*CustomFileDialogPreviewCallback)(const char* path, const Rect& previewRect, void* userData);

Draws a preview of the currently selected entry in the custom file dialog. When non-null a preview panel is shown on the right.

  • path the full absolute path of the selected entry
  • previewRect the rectangle where the preview should be drawn (window coordinates)
  • userData the user data passed to customFileDialog

2D math structs

struct Point { f32 x, y; };

A 2D point with a full set of arithmetic operators, dot, normalize, getLength, isOnLine, etc.

struct SplineControlPoint { Point leftTangent, center, rightTangent; bool isLine; NodeType type; };

A spline control point with optional tangents, used by renderDrawSpline.

struct Rect { f32 x, y, width, height; };

An axis-aligned rectangle with helpers: contains, expand/contract, clipInside, edges and corners.

struct Color { f32 r, g, b, a; };

A color with float RGBA channels (0..1). Converts to/from packed Rgba32, has arithmetic operators and a set of named constants (Color::red, Color::darkBlue, Color::white…).

struct LineStyle { Color color; f32 width; bool useStipple; f32 stipplePattern[8]; u32 stipplePatternCount; f32 stipplePhase; };

Line drawing style. The stipple pattern alternates dash and empty sizes (e.g. {5, 5}).

struct FillStyle { Color color; HImage image; Point scale; };

Filled primitive style with an optional image and scale.

Input types

struct InputEvent

An input event pushed to the input queue by an input provider and read with inputEventGet.

InputEvent::Type: None, MouseMove, MouseDown, MouseUp, MouseWheel, Key, Text, WindowMoved, WindowResized, WindowGotFocus, WindowLostFocus, WindowMouseEnter, WindowMouseLeave, WindowClose, OsDragDrop.

Union payload fields mouse (MouseData), key (KeyData), text (TextData), drop (OsDragDropData) are valid per the type. The affected window (HNativeWindow) is also stored.

Render types

struct Vertex { Point position; Point uv; u32 color; };

A vertex used by the Services::draw graphics callback.

struct RenderBatch

A single draw call over a vertex range; the renderer splits the UI into batches per texture and state.

RenderBatch::PrimitiveType: TriangleList, TriangleStrip, TriangleFan. Fields: texture, startVertexIndex, vertexCount.

struct ImageData { Rgba32* pixels; u32 width; u32 height; };

Raw RGBA pixel data of an image.

struct PackedRect { u64 id; Rect rect; bool packedOk; };

A rectangle packed in the atlas by the Services::packRects callback.

Font types

struct FontGlyph

A rasterized glyph filled by the Services::rasterizeFontGlyph callback: image, code, bearings, advance, bitmap metrics and RGBA buffer.

struct FontMetrics { f32 height, ascender, descender, underlinePosition, underlineThickness; };

Line metrics of a font face.

struct FontTextSize

The measured size of a text: width, height, maxBearingY, maxGlyphHeight, maxLength.

struct FontInfo { HFontFace fontFace; FontMetrics metrics; };

A loaded font face and its metrics, filled by Services::loadFont.

Display & docking structs

struct DisplayInfo

Info about a monitor: name, index, bounds, usableBounds, scale.

struct WindowsDockingState

The saved window docking layout, filled by dockingStateSave and restored by dockingStateLoad. Lists every dock node and its docked windows.

struct VirtualScrollInfo

Virtual list state for virtualListContentBegin: totalItemCount, itemHeight, startIndex, endIndex, scrollOffsetY, plus a nextStep() helper.

Theme helpers

struct WidgetElementInfo

The visual description of a widget element: image, border (9-cell), color, textColor, font, width, height, textShadow.

struct TextShadow

Embossed/outline text shadow settings: color, offsetX, offsetY, enabled.

struct KeywordInfo

A syntax-highlight keyword and its color for the multiline text input: keyword, color, type (Keyword/Delimiter).

struct RangeHighlight

Colors the text between beginKeyword and endKeyword (with optional escapeKeyword) in the multiline text input.
