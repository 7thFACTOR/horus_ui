Widgets

All built-in widgets: boxes, popups, message boxes, buttons, inputs, sliders, images, progress, checks, radio, labels, expandable, tree, dropdown, list, selectable, link, separators, viewport, menus, tabs, and immediate state queries.

Boxes

void boxBegin(const char* id, const Color& tintColor, WidgetElementId widgetElementId = WidgetElementId::BoxBody, WidgetStateType state = WidgetStateType::Normal, f32 customHeight = 0.0f)

Begin drawing a box, which may contain other widgets.

  • id the box id
  • tintColor the box tint color
  • widgetElementId the widget element id image to use when drawing the box
  • state the widget element state to draw with
  • customHeight a forced custom height, otherwise auto calculated from child widgets
void boxBeginUserElement(const char* id, const Color& tintColor, const char* userElementName, WidgetStateType state = WidgetStateType::Normal, f32 customHeight = 0.0f)

Begin drawing a box using a user element from the theme.

bool boxEnd()

End the box layout.

Returns true if the box was drawn.

Popups & message boxes

void popupBegin(const char* id, f32 width, PopupFlags flags = PopupFlags::BelowLastWidget, const Point& position = Point(), WidgetElementId widgetElementId = WidgetElementId::PopupBody)

Begin drawing a modal popup widget on top of all other popups or widgets.

  • id the popup id
  • width the width of the popup
  • flags the popup flags (PopupFlags)
  • position custom window coordinates of the popup
  • widgetElementId element theme to draw the popup body
void popupEnd()

End a popup widget.

void popupClose()

Close the current popup, used inside begin/endPopup.

bool popupMustClose()

Return true if the popup must be closed due to user input.

bool popupClickedOutside()

Return true if the user clicked outside popup's rect.

bool popupMouseOutside()

Return true if mouse is outside popup's rect.

bool popupPressedEscape()

Return true if the user pressed escape while current popup is active.

MessageBoxButtons messageBox(const char* title, const char* message, MessageBoxButtons buttons = MessageBoxButtons::Ok, MessageBoxImage img = MessageBoxImage::Info, u32 width = 400, HImage customImg = 0)

Draw a message box popup.

  • title the message box title
  • message the message
  • buttons the visible buttons flags
  • img the image of the message box
  • width the width of the message box
  • customImg the custom image if set in img param

Returns the pushed button in the message box.

Widget state control

void widgetSetNextDisabled(bool disabled = true)

Set the next widget as disabled.

void widgetPushDisabled(bool disabled = true)

Nest the disabled state; all widgets inside will be disabled.

void widgetPopDisabled()

Pop the disabled nesting state.

bool widgetGetDisabled()

Return true if the next widget will be disabled (either by parent or next-state).

void widgetSetNextFocused()

Set next widget as focused.

Buttons

bool button(const char* label)

Draw a button widget.

  • label the button text

Returns true if button was pressed.

bool buttonGroup(const char* id, const char** labels, u32 count, u32* currentIndex)

Draw a group of segment buttons, only one is selected at a time.

bool buttonGroup(const char* id, const char** labels, u32 count, u32* currentIndex, bool fullWidth)

Draw a group of segment buttons with full width option.

  • fullWidth if true buttons share full available layout width equally
bool imageButton(HImage img, f32 width, f32 height, HImage disabledImg = 0, bool down = false)

Draw a button with an image on it.

  • img the image
  • width the button width
  • height the button height, if zero takes image height
  • disabledImg image for disabled state
  • down if true button is in pressed state

Returns true if the button was pressed.

Text inputs

bool textInput(const char* id, char* text, u32 maxTextSize, TextInputFlags flags = TextInputFlags::None, const char* defaultText = nullptr, HImage img = 0, bool password = false, const char* passwordChar = "*")

Draw a text input widget.

  • id the widget id
  • text the text to be edited, provided by user
  • maxTextSize the max size of the text buffer
  • flags various flags for text input (TextInputFlags)
  • defaultText the grayed default text when there is no text value
  • img the image drawn in the widget
  • password true for password mode
  • passwordChar the password mask character

Returns true if the text was modified.

bool textInputMultiline(const char* id, char* text, u32 maxTextSize, u32 visibleLines = 10, MultilineTextInputFlags flags = MultilineTextInputFlags::None, const KeywordInfo* keywords = nullptr, u32 keywordCount = 0, const RangeHighlight* rangeHighlights = nullptr, u32 rangeHighlightCount = 0)

Multi-line text input widget. Enter key creates a new line instead of submitting.

Sliders

bool sliderInt(const char* id, i32 minVal, i32 maxVal, i32& value, bool useStep = false, i32 step = 0)

Draw an integer number slider widget.

bool sliderFloat(const char* id, f32 minVal, f32 maxVal, f32& value, bool useStep = false, f32 step = 0)

Draw a float number slider widget.

bool comboSliderInt(i32* value, f32 stepsPerPixel = 1.0f, i32 arrowStep = 1, const char* formatStr = nullptr, const char* indeterminateStr = nullptr)

Draw an integer combo slider widget. Pass nullptr for indeterminate state.

bool comboSliderIntRanged(i32* value, i32 minVal, i32 maxVal, f32 stepsPerPixel = 1, i32 arrowStep = 1.0f, const char* formatStr = nullptr, const char* indeterminateStr = nullptr)

Draw an integer combo slider widget with a min/max range.

bool comboSliderFloat(f32* value, f32 stepsPerPixel = 1.0f, f32 arrowStep = 1.0f, const char* formatStr = nullptr, const char* indeterminateStr = nullptr)

Draw a float combo slider widget.

bool comboSliderFloatRanged(f32* value, f32 minVal, f32 maxVal, f32 stepsPerPixel = 1.0f, f32 arrowStep = 1.0f, const char* formatStr = nullptr, const char* indeterminateStr = nullptr)

Draw a float combo slider widget with a min/max range.

bool circularSliderFloat(const char* label, f32* value, f32 minVal, f32 maxVal, f32 step, bool twoSide = false, f32 fineStepDivideFactor = 10.f, CircularSliderFlags flags = CircularSliderFlags::Normal)

Draw a circular slider widget, the value is changed by rotating the mouse around the slider.

  • label the widget label
  • value the value pointer
  • minVal the minimum value
  • maxVal the maximum value
  • step the step per mouse rotation amount
  • twoSide if true the slider is two sided (angle 180 degrees)
  • fineStepDivideFactor divides the step for fine control when a modifier key is held
  • flags the circular slider flags (CircularSliderFlags)

Returns true if the value was modified.

Images

bool image(HImage image, f32 height = 0, HAlignType horizontalAlign = HAlignType::Center, VAlignType verticalAlign = VAlignType::Center, ImageFitType fit = ImageFitType::KeepAspect)

Draw an image widget.

  • image the image to draw
  • height the height of the image, if zero uses actual image height
  • horizontalAlign the horizontal image align mode
  • verticalAlign the vertical image align mode
  • fit how the image is fitted in the rectangle

Returns true if it was clicked on.

bool texture(HTexture texture, f32 textureWidth, f32 textureHeight, f32 height = 0, HAlignType horizontalAlign = HAlignType::Center, VAlignType verticalAlign = VAlignType::Center, ImageFitType fit = ImageFitType::KeepAspect)

Draw a texture widget.

Separators & spacing

void line()

Draw a horizontal line widget.

void space(f32 customSpacing = 0.0f)

Leave a normal space between previous widget and next one.

void sameLine(f32 offsetX = 0.0f, f32 spacing = 0.0f)

Make the next widget appear on the same line as the previous widget. After each widget, same-line mode automatically ends.

void widgetSetNextWidth(f32 width)

Set the width of the next widget drawn, overriding the default widget width.

Viewport

Rect viewportBegin(const char* id, f32 height = 0)

Begin a custom user viewport area.

  • height the height of the viewport, if zero takes entire remaining container height

Returns the rectangle in window coordinates of the actual viewport area.

void viewportEnd()

End the current user viewport.

Immediate state queries

bool widgetIsHovered()

Return true if the previous widget is hovered.

bool widgetIsFocused()

Return true if the previous widget is focused.

bool widgetIsPressed()

Return true if the previous widget is pressed down.

bool widgetIsClicked()

Return true if the previous widget is clicked.

bool widgetIsVisible()

Return true if the previous widget is visible.

bool widgetIsChangeEnded()

Return true if the change for the widget's value ended; used for undo systems to add the undo action only after the drag/edit ended.

WidgetId widgetGetId()

Return the current widget id (the next widget's id).

Point widgetGetPosition()

Return the current drawing position of widgets in the current layout, in unscaled pixels.

void widgetSetPosition(const Point& position)

Set the drawing position of the next widget.

void widgetPushPosition()

Push the current widget drawing position; after this you can move the widget position and restore it later.

void widgetPopPosition()

Pop the previously pushed widget drawing position.

Rect widgetGetRect()

Return the rectangle of the previous widget, in window coordinates.

Point mouseGetPosition()

Return the current mouse position inside current window.

void mouseSetPosition(const Point& pos)

Set the mouse position in screen coordinates.
