Parameters & settings

Finish the look without extra images: a handful of numeric and color knobs live as string values inside element descriptions, plus a few theme-level settings.

Remember: parameters must be JSON strings The loader (backends/json_theme_loader.cpp) only stores an element member as a parameter when its value is a string. Numeric values are ignored by the loader (the widgets then use their code default). Write "indent": "10", not "indent": 10.

Style parameters

Style parameters are element-level members (siblings of normal/hovered/…) and are read by the widget code with themeGetWidgetElementParameterFloat() and themeGetWidgetElementParameterColor(). The table lists every parameter currently consumed by the library.

ParameterElementKindDefaultDescription
indent treeNodeBody float 20 Per-level horizontal indent of child rows.
labelSideSpacing buttonGroupLeftBody, buttonGroupMiddleBody, buttonGroupRightBody float settings.defaultButtonGroupLabelSideSpacing Horizontal space between the group’s label and its edge (win94 uses "6").
bulletTextSpacing checkBody, radioBody float settings.defaultBulletTextSpacing Gap between the bullet/box and the label text.
paddingX, paddingY windowBody, tabBodyActive, tabBodyInactive float 10 / 10 Inner padding between the 9-slice border and content.
barTextSpacing progressFill float 4 Space between the fill edge and the percentage text.
textShadowColor progressFill color black Shadow color of the percentage text.
labelSpacing circularSliderBody float settings.defaultCircularSliderLabelSpacing Space between the slider ring and the value label.
count circularSliderValueDot float 20 Number of value dots shown in the selected range.
placementRadius circularSliderValueDot float 35 Radius where dots are placed around the center.
placementRadius circularSliderMark float 25 Radius where the tick marks are placed.
limitOffset circularSliderValueDot float 0.3 Angular offset at the start/end of the dot range.
negativeColor circularSliderValueDot color white Color of dots in the "negative" part of the range.
positiveColor circularSliderValueDot color white Color of dots in the "positive" part of the range.
rowHeight tableBody float 25 Default table row height when a column does not impose its own.
rowAltBgColor0, rowAltBgColor1 tableBody color transparent Alternate row background colors (zebra striping).
innerBorderColorH, innerBorderColorV tableBody color white Color of the horizontal/vertical grid lines inside the table.
outerBorderColorH, outerBorderColorV tableBody color white Color of the table’s outer border lines.
columnResizeLineColor tableBody color cyan Color of the drag line while resizing a column.
borderColorV, borderColorH tableHeaderBody color white Color of the vertical/horizontal separators in the header row.

Parameters are per style: two button styles in the same theme can disagree on labelSideSpacing or any other knob. They are free-form key/value pairs, so custom widgets can define and read their own parameter names.

Theme settings

The top-level settings object is a generic string store managed by themeSetUserSetting() / themeGetUserSetting(). The library and the host application decide what the names mean. Names currently referenced by the shipped themes:

SettingConsumed byMeaning
sameLineHeight Host application Reference line height, in pixels, used to vertically center widgets placed on the same line ("22" in all shipped themes).
dockPreviewNativeWindowsColorTint docking.cpp Color string tinting the dock preview previewed as a native OS window overlay.
dockPreviewInsideWindowsColorTint docking.cpp Color string tinting the in-window dock preview guides.

Any setting can be read at runtime, in C++:

const char* h = hui::themeGetUserSetting(hui::themeGet(), "sameLineHeight");  // "22"
