Element names

Widget names map a "widgets" entry to a built-in WidgetType, and element names inside a style map to a built-in WidgetElementId. The tables below are the exact strings recognized by the loader (getWidgetTypeFromName() / getWidgetElementFromName()), with the JSON key on the left and the internal enum on the right.

User widgets and user elements A widget name not in the first table, or an element name not in the second table, is stored as a user element and addressable by string name through the user-element API (themeSetUserWidgetElement() and friends).
